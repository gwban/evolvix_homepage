# 이볼빅스 홈페이지 카피 가이드

홈페이지 문구를 새로 쓰거나 고칠 때 참고하는 기준입니다.
목표는 하나입니다. **현장 엔지니어가 읽었을 때 "이 회사는 우리 일을 안다"고 느끼게 쓰는 것.**

## 왜 "AI가 쓴 것 같다"는 느낌이 나는가

AI가 쓴 글은 문법은 맞는데 **누구에게나 해당되는 말**로 채워져 있습니다.
아래 패턴이 반복되면 읽는 사람이 바로 알아챕니다.

| 패턴 | 예시 (피할 것) | 이유 |
|---|---|---|
| 추상명사 | 혁신, 가치, 신뢰, 파트너십, 최적화 | 어느 회사에나 붙일 수 있는 말 |
| "A가 아니라 B" | "장비가 아니라 솔루션입니다" | AI 문장에서 가장 흔한 구조 |
| 대구 남발 | "더 빠르게, 더 정확하게, 더 스마트하게" | 리듬만 있고 정보가 없음 |
| "~를 넘어" | "검사를 넘어 혁신으로" | 의미 없는 확장 |
| 명사형 종결 반복 | "새로운 기준. 새로운 경험." | 광고 흉내 |
| 영어 라벨 | Our Approach, Reliability | 한국어 사이트에서 어색함 |
| 4개씩 맞춘 목록 | 가치 4개, 특징 4개, 장점 4개 | 내용보다 칸을 채운 느낌 |
| 과한 약속 | "완벽한 품질을 약속합니다" | 근거 없는 주장 |

## 선진 기업 카피의 공통점

Apple, Keyence, Cognex처럼 기술 제품을 잘 파는 회사의 문구에는 공통점이 있습니다.

1. **구체적인 사물과 동작을 말합니다.** "품질 향상" 대신 "스크래치를 찾습니다".
2. **고객의 말투를 씁니다.** 고객이 실제로 하는 말("자꾸 놓친다", "사람마다 다르다")에서 시작합니다.
3. **짧고 평범한 문장을 씁니다.** 꾸미는 말을 빼도 뜻이 같으면 뺍니다.
4. **할 수 있는 것만 말합니다.** 검증하지 않은 숫자나 최상급 표현을 쓰지 않습니다.
5. **한 덩어리에는 메시지 하나만 둡니다.**

## 이 사이트에서 바꾼 예

| 이전 | 이후 |
|---|---|
| 결함이 생기기 전에, 먼저 감지합니다. | 불량은 라인에서 잡고, 고장은 멈추기 전에 막습니다. |
| Reliability · 검증된 신뢰 | 먼저 테스트하고, 결과를 보여 드립니다. |
| Innovation · 새로운 접근 | 정해진 장비를 끼워 맞추지 않습니다. |
| 센서 노드부터 서버까지, 하나의 무선 시스템 | 롤에는 무선 노드만 붙이면 됩니다. |
| 함께 변화의 물결을 만들어 갑니다. | 어떤 공정인지 알려 주세요. |

## 쓰고 나서 확인할 것

- [ ] 우리 회사 이름을 다른 회사 이름으로 바꿔도 말이 되는가? → 그렇다면 다시 쓴다.
- [ ] 결함 이름, 소재 이름, 설비 이름 같은 **구체적인 단어**가 들어 있는가?
- [ ] 소리 내어 읽었을 때 영업 담당자가 고객에게 실제로 할 법한 말인가?
- [ ] 확인하지 않은 숫자나 "최고", "완벽" 같은 표현이 없는가?
- [ ] 한국어 페이지에 영어 라벨이 필요 이상으로 들어가 있지 않은가?
- [ ] 영문 페이지는 한국어를 직역하지 않고, 영어로 자연스럽게 다시 썼는가?
