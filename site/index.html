About

제조 현장의 데이터를
실제 기술과 성과로 연결합니다.

주식회사 이볼빅스는 AI, 컴퓨터 비전, IoT 기술을 기반으로 제조 현장의 품질 검사와 설비 상태 모니터링 문제를 해결하는 산업 기술 기업입니다.

알고리즘 개발에 머무르지 않고 산업용 카메라, 센서, MCU, 엣지 컴퓨팅 시스템을 연동하여 실제 제조 현장에서 작동하는 기술을 개발하고 검증합니다.

Core Technology
  • AI

Problem

작은 롤 이상이
제품 결함으로 이어집니다.

롤투롤 공정에서 가이드롤의 열화와 회전 이상은 눈에 잘 띄지 않지만, 공정 전체의 품질에 영향을 줍니다.

01

가이드롤 열화 · 회전 이상

장시간 운전으로 베어링과 롤 상태가 저하되면 회전이 불안정해집니다.

→
02

장력 불균형

→
03

제품 스크래치 · 품질 결함

스크래치, 주름 등 제품 결함으로 이어져 품질과 생산성에 손실을 줍니다.

Our Approach

  • 회전·진동 이상 조기 감지
  • 가이드롤 열화 상태 사전 파악
  • 최적 시점의 예지보전
  • 품질 결함과 비계획 정지 예방
Product

RMS-ON

롤투롤 공정용 무선 예지보전 솔루션. 수백 개 가이드롤의 RPM·진동 데이터를 무선으로 수집하고, 이상 징후를 조기에 감지하는 스마트 모니터링 플랫폼입니다.

System

센서 노드부터 서버까지, 하나의 무선 시스템

RMS-ON Edge Zigbee → RMS-ON Gateway Ethernet / Wi-Fi → On-premise Server
Product 01

RMS-ON Edge

비접촉 광학식 RPM 센서와 3축 MEMS 가속도 센서를 통합한 배터리 구동형 무선 센서 노드입니다. Zigbee/XBee 기반 통신과 TDMA 수집 구조로 다수의 가이드롤 상태 데이터를 주기적으로 수집하고, 측정 후 절전 상태로 전환하여 장기간 운용이 가능합니다.

Product 02

RMS-ON Gateway

다수의 RMS-ON Edge 엔드노드로부터 Zigbee 기반 센싱 데이터를 수집하고, 이더넷 또는 Wi-Fi를 통해 온프레미스 서버와 연동하는 데이터 중계 장치입니다. 현장 상태 LED와 외장 안테나로 네트워크 상태를 직관적으로 확인할 수 있습니다.
